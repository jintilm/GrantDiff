# GrantDiff v1.1.0-preview.1

This preview adds a local interactive report viewer to the Kubernetes RBAC review CLI. Generate an offline HTML file with `grantdiff view`, then open it in a browser to explore existing schema 1.0 diff reports.

## Changes

- Filter permission changes by identity, change type, high risk, namespace range and text.
- Compare before/after decisions and expand authorization paths, aggregation and source locations.
- Keep incomplete analysis and input diagnostics visible, with distinct empty-report and no-match states.
- Switch between English and Chinese, paginate large lists, and use the responsive layout on narrow screens.
- Read reports through the local file picker or embed one with `--input`. Scripts, styles and the schema are included in the generated file.
- Verify the browser interactions and generated HTML as part of native Windows/Linux package checks.

## Try it

Use `./grantdiff` on Linux or `./grantdiff.exe` on Windows after extracting the archive.

```text
./grantdiff diff --before examples/external-dns/before --after examples/external-dns/after --catalog examples/external-dns/catalog.yaml --compact --format json --output report.json
./grantdiff view --input report.json --output review.html
```

Open `review.html` in a current Chromium browser. The page embeds the complete report and works offline. The archive also includes `viewer.html` with a local file picker. `view --output review.html` generates an empty viewer. JSON inputs are limited to 128 MiB. The preview's browser checks cover 5,000 synthetic ranges and the supplied authorization examples.

This is a viewer preview following the v1.0 release candidate. Its validation and browser coverage are documented with the release. Feedback from outside users remains part of stable-release acceptance.
